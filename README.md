# 🍰 下午茶轉盤 (Afternoon Tea Wheel)

這是一個專為辦公室下午茶設計的桌面應用程式，整合了「轉盤抽籤」、「團購點餐」與「公費管理」功能，讓決定下午茶吃什麼變得更有趣且高效率！

## ✨ 功能特色

### 🎰 命運轉盤

- **視覺化轉盤**：精美的轉盤動畫，解決「今天吃什麼」的選擇困難症。
- **公平演算法**：中獎過的店家權重會暫時歸零，沒中獎的店家權重會增加，確保大家想吃的都有機會吃到。
- **直接選擇**：如果不想抽籤，也可以直接從列表中選擇店家開團。

### 📝 團購點餐
- **🧠 AI 智慧辨識菜單 (NEW!)**：
  - **一鍵掃描**：整合 Google Gemini AI，將複雜的菜單圖片直接轉化為點餐介面。
  - **結構化資料**：自動分析品項、價格、分類與客製化選項（如：甜度、冰塊、加料）。
  - **強大計價邏輯**：精準支援「免費配料額度」與「超額加收費用」計算（如：豆花任選 2 種料免費，第 3 樣起 +10 元）。
  - **邏輯自動補全**：AI 會根據菜單內容自動推論限制（如：冰沙不提供加熱）。
- **多團購並行**：支援同時開啟多家店的團購 Session (分頁顯示)。
- **即時點餐**：成員可輸入姓名、品項、價格與備註。
- **智慧填寫**：輸入姓名後，系統會自動帶入您上次在這家店點的餐點，省時又方便！
- **截止倒數**：顯示剩餘時間，時間到自動鎖定無法點餐。
- **菜單瀏覽**：
  - 支援高解析度菜單圖片。
  - **互動式縮放**：點擊放大、滾輪縮放、拖曳平移，看清楚菜單上的每一個字。
- **便捷操作**：
  - **一鍵複製**：快速複製開團文案 (包含店家、截止時間)，方便貼到通訊軟體 (Line/Slack)。
  - **Excel 匯出**：將訂單匯出成 Excel 表格，方便統計與訂餐。

### 🏪 店家管理

- 輕鬆新增、編輯、刪除店家資訊。
- 支援上傳菜單圖片。
- **自動編號**：店家 ID 自動遞增，方便管理。

### 💰 公費管理

- 記錄公費的收入與支出。
- **自動結帳**：團購結帳時，自動計算總金額並從公費中扣除 (或記錄支出)。
- 隨時查看公費餘額與歷史明細。

### ⚙️ 系統設定

- **資料路徑設定**：初次執行時可選擇資料儲存位置。支援指向 **網路磁碟機** 或 **雲端同步資料夾** (如 Dropbox/Google Drive)，輕鬆實現辦公室多人共用資料。
- **深色模式**：預設採用深色主題，護眼又時尚。

## 🚀 安裝說明

本程式提供 Windows 版本，安裝後即可使用。

1.  **下載安裝檔**：
    - `下午茶 Setup 1.0.0.exe` (安裝版)
2.  **安裝位置**：
    - 預設安裝於使用者目錄：`%LOCALAPPDATA%\Programs\Afternoon Tea Wheel`
3.  **資料儲存**：
    - 預設儲存於：`%APPDATA%\afternoon_tea\data`
    - 若需多人共用，請在初次啟動時選擇共用資料夾，或在設定中更改路徑。

## 📖 使用手冊

### 1. 決定下午茶

1.  進入首頁，點擊 **「+ 決定下午茶」**。
2.  選擇 **「命運之輪」** 進行抽籤，或是 **「直接選擇店家」**。
3.  確認店家後，設定 **截止時間**，點擊 **「確認開團」**。

### 2. 大家來點餐

1.  在首頁下方會出現進行中的團購卡片。
2.  點擊卡片進入點餐頁面。
3.  **AI 智慧點餐**：點擊 **「AI 智慧辨識」**，系統會掃描菜單並列出所有品項。
4.  **選擇餐點**：直接點擊感興趣的品項，系統會自動開啟客製化視窗（包含規格、甜度、配料等）。
5.  **動態計價**：選取配料時，系統會自動根據店家的免費額度計算加價金額，並即時更新總價。
6.  確認無誤後，點擊 **「送出訂單」**。

### 3. 結算與訂購

1.  時間截止後，發起人可點擊 **「複製」** 按鈕，將開團資訊貼到群組提醒大家。
2.  點擊 **「匯出」** 下載 Excel 訂單表，傳真或電話訂餐。
3.  餐點送達付款後，點擊 **「結帳」**，系統將自動記錄公費支出。

## 🛠️ 技術堆疊 (Tech Stack)

本專案採用現代化的前端與桌面應用開發技術：

- **核心框架**：[Electron](https://www.electronjs.org/) + [Vue 3](https://vuejs.org/)
- **AI 引擎**：[Google Gemini AI](https://deepmind.google/technologies/gemini/) (強大的多模態模型辨識)
- **建置工具**：[Vite](https://vitejs.dev/) (極速開發體驗)
- **UI 框架**：[Tailwind CSS](https://tailwindcss.com/) (樣式) + [Element Plus](https://element-plus.org/) (部分元件)
- **資料處理**：[XLSX](https://github.com/SheetJS/sheetjs) (Excel 匯出)
- **打包工具**：[Electron Builder](https://www.electron.build/)

## 🛠️ 開發者指南 (Development)

如果你想自行修改或編譯程式碼：

### 環境需求
- Node.js (建議 v16 以上)
- npm

### 指令列表

```bash
# 安裝依賴
npm install

# 啟動開發模式 (同時啟動 Vite 與 Electron)
npm run app:dev

# 單獨啟動網頁版 (不含 Electron API)
npm run dev

# 打包應用程式 (Windows)
# 輸出檔案位於 release/ 資料夾 (安裝檔與免安裝版)
npm run electron:build
```

### 專案結構

- `electron/`: Electron 主進程 (Main Process)，負責視窗管理、檔案讀寫、IPC 通訊。
  - `prompt/`: AI 提示詞資料夾。
    - `prompt.md`: AI 提示詞檔案。
  - `jsonService.cjs`: JSON 格式的檔案讀寫服務。
  - `main.cjs`: 應用程式入口點。
  - `preload.cjs`: 預載入腳本，安全地暴露 API 給渲染進程。
- `src/`: Vue 3 前端介面 (Renderer Process)。
  - `views/`: 頁面元件
    - `HomeView.vue`: 首頁 (轉盤、進行中團購)。
    - `OrderView.vue`: 點餐頁面 (菜單、下單)。
    - `AdminView.vue`: 後台管理 (店家管理、成員管理)。
    - `FinanceView.vue`: 公費管理 (收支記錄)。
    - `HistoryView.vue`: 歷史紀錄 (查看過去的開團紀錄)。
  - `components/`: 重用元件
    - `Wheel.vue`: 轉盤元件。
    - `OrderForm.vue`: 點餐表單。
    - `ShopManager.vue`: 店家管理元件。
    - `MemberManager.vue`: 成員管理元件。
    - `ZoomableImageModal.vue`: 圖片放大檢視元件。
    - `CustomDatePicker.vue`: 自訂日期選擇器。
    - `TitleBar.vue`: 自訂視窗標題列。
  - `router/`: 路由設定。
