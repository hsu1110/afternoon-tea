# 下午茶轉盤程式計畫 (Afternoon Tea Wheel Plan)

## 專案目標
建立一個下午茶轉盤程式，方便使用者隨機選擇下午茶。
**變更**: 使用 Electron + 共用 Excel 檔案。

## 需求分析
1.  **轉盤功能**: 隨機選擇下午茶選項。
2.  **資料來源**: 讀取一個外部的 Excel 檔案 (`.xlsx`)。
3.  **資料維護**: 內容包含名稱、電話、網址。
    *   **維護方式**: 使用者直接開啟 Excel 檔案進行編輯、新增、刪除。
    *   **程式腳色**: 程式只負責「讀取」Excel 並顯示轉盤，避免檔案鎖定問題。
4.  **可攜性**: 打包成 `.exe` 執行檔。
5.  **共同維護**: Excel 檔案放置於共用資料夾 (NAS / File Server)，大家都能存取。

## 技術架構 (定案)

### 核心技術
*   **框架**: Electron (Node.js + Chromium)
*   **語言**: HTML, CSS, JavaScript (Frontend), Node.js (Backend logic)
*   **Excel 處理**: `xlsx` (SheetJS) 套件
*   **打包工具**: `electron-builder`

### 運作流程
1.  **啟動**: 程式啟動時，讀取設定檔 (例如 `config.json`) 取得 Excel 檔案路徑。
    *   *註：設定檔可讓使用者自己指定 Excel 在哪裡，不需要重新打包程式。*
2.  **讀取**: 使用 `xlsx` 套件讀取 Excel 內容。
3.  **顯示**: 將資料轉換為轉盤選項，渲染畫面。
4.  **抽取**: 點擊按鈕，執行轉盤動畫，顯示結果。

### 資料結構 (Excel 範例)
| 店名 (Name) | 電話 (Phone) | 網址 (URL) | 權重 (Weight) |
| :--- | :--- | :--- | :--- |
| 50嵐 | 02-12345678 | https://... | 1 |
| 星巴克 | 02-87654321 | https://... | 1 |

*(權重可選，預設為 1)*
